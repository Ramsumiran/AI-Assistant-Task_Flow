
# TaskFlow

TaskFlow is a full-stack task and project management application built with FastAPI, SQLAlchemy, PostgreSQL/Supabase, HTML, CSS, and JavaScript.

## Features

- User registration
- User login
- JWT authentication
- Project management
- Task CRUD operations
- Task search
- Task filtering
- Task priority sorting
- Task statistics
- Custom algorithms
- AI Assistant
- Responsive dashboard

## Technologies

### Backend

- Python
- FastAPI
- Uvicorn
- SQLAlchemy
- PostgreSQL
- Supabase
- psycopg2
- JWT
- Passlib
- bcrypt

### Frontend

- HTML5
- CSS3
- JavaScript
- Fetch API

### AI

- AI Assistant
- OpenAI API integration
- Environment variables for API keys
